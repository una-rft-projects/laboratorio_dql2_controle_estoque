Objetivo

  • Praticar INNER, LEFT, RIGHT e FULL JOIN conceitual.
  • Utilizar COUNT, SUM, AVG, MIN e MAX.

  • Construir subconsultas.

Etapa 3 — Criando PRODUTO

SQL
CREATE TABLE produto (
    id_produto INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(150) NOT NULL,
    sku VARCHAR(30) NOT NULL UNIQUE,
    preco DECIMAL(10,2) NOT NULL,
    estoque_minimo INT NOT NULL DEFAULT 0,
    id_categoria INT,

    CONSTRAINT chk_preco
        CHECK (preco >= 0),

    CONSTRAINT chk_estoque_minimo
        CHECK (estoque_minimo >= 0),

    CONSTRAINT fk_produto_categoria
        FOREIGN KEY (id_categoria)
        REFERENCES categoria(id_categoria)
);

Etapa 4 — Criando FORNECEDOR

SQL
CREATE TABLE fornecedor (
    id_fornecedor INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(150) NOT NULL,
    cnpj VARCHAR(18) NOT NULL UNIQUE,
    email VARCHAR(150)
);

Etapa 5 — Criando PRODUTO_FORNECEDOR

SQL
CREATE TABLE produto_fornecedor (
    id_produto INT NOT NULL,
    id_fornecedor INT NOT NULL,
    preco_compra DECIMAL(10,2),

    PRIMARY KEY (
        id_produto,
        id_fornecedor
    ),

    CONSTRAINT fk_pf_produto
        FOREIGN KEY (id_produto)
        REFERENCES produto(id_produto),

    CONSTRAINT fk_pf_fornecedor
        FOREIGN KEY (id_fornecedor)
        REFERENCES fornecedor(id_fornecedor)
);

Etapa 6 — Criando MOVIMENTACAO_ESTOQUE

SQL
CREATE TABLE movimentacao_estoque (
    id_movimentacao INT AUTO_INCREMENT PRIMARY KEY,
    id_produto INT NOT NULL,
    tipo VARCHAR(10) NOT NULL,
    quantidade INT NOT NULL,
    data_movimentacao DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_tipo_movimentacao
        CHECK (tipo IN ('ENTRADA', 'SAIDA')),

    CONSTRAINT chk_quantidade
        CHECK (quantidade > 0),

    CONSTRAINT fk_movimentacao_produto
        FOREIGN KEY (id_produto)
        REFERENCES produto(id_produto)
);

Etapa 8 — JOINs

INNER JOIN

SQL
SELECT
    p.nome AS produto,
    c.nome AS categoria
FROM produto p
INNER JOIN categoria c
    ON p.id_categoria = c.id_categoria;

LEFT JOIN

SQL
SELECT
    p.nome AS produto,
    c.nome AS categoria
FROM produto p
LEFT JOIN categoria c
    ON p.id_categoria = c.id_categoria;

RIGHT JOIN

SQL
SELECT
    p.nome AS produto,
    c.nome AS categoria
FROM produto p
RIGHT JOIN categoria c
    ON p.id_categoria = c.id_categoria;

FULL JOIN conceitual

SQL
SELECT
    p.nome AS produto,
    c.nome AS categoria
FROM produto p
LEFT JOIN categoria c
    ON p.id_categoria = c.id_categoria

UNION

SELECT
    p.nome AS produto,
    c.nome AS categoria
FROM produto p
RIGHT JOIN categoria c
    ON p.id_categoria = c.id_categoria;

Produto + Fornecedor

SQL
SELECT
    p.nome AS produto,
    f.nome AS fornecedor,
    pf.preco_compra
FROM produto p
INNER JOIN produto_fornecedor pf
    ON p.id_produto = pf.id_produto
INNER JOIN fornecedor f
    ON pf.id_fornecedor = f.id_fornecedor;

Etapa 9 — Funções de agregação

COUNT
SELECT COUNT(*) AS total_produtos
FROM produto;
AVG
SELECT AVG(preco) AS preco_medio
FROM produto;
MIN / MAX
SELECT
    MIN(preco) AS menor_preco,
    MAX(preco) AS maior_preco
FROM produto;

Etapa 10 — GROUP BY e HAVING

Quantidade de produtos por categoria

SQL
SELECT
    c.nome AS categoria,
    COUNT(p.id_produto) AS quantidade
FROM categoria c
LEFT JOIN produto p
    ON c.id_categoria = p.id_categoria
GROUP BY
    c.id_categoria,
    c.nome;

Somente categorias com 2 ou mais produtos

SQL
SELECT
    c.nome AS categoria,
    COUNT(p.id_produto) AS quantidade
FROM categoria c
JOIN produto p
    ON c.id_categoria = p.id_categoria
GROUP BY
    c.id_categoria,
    c.nome
HAVING COUNT(p.id_produto) >= 2;
Regra: WHERE filtra linhas. HAVING filtra grupos após o GROUP BY.

Etapa 11 — Subconsultas

Produto mais caro

SQL
SELECT
    nome,
    preco
FROM produto
WHERE preco = (
    SELECT MAX(preco)
    FROM produto
);

Produtos acima da média

SQL
SELECT
    nome,
    preco
FROM produto
WHERE preco > (
    SELECT AVG(preco)
    FROM produto
);

Etapa 12 — Calculando estoque atual

ENTRADA → soma SAÍDA → subtrai
SQL
SELECT
    p.nome,

    SUM(
        CASE
            WHEN m.tipo = 'ENTRADA'
                THEN m.quantidade
            WHEN m.tipo = 'SAIDA'
                THEN -m.quantidade
        END
    ) AS estoque_atual

FROM produto p

JOIN movimentacao_estoque m
    ON p.id_produto = m.id_produto

GROUP BY
    p.id_produto,
    p.nome;

Produtos sem movimentação

SQL
SELECT
    p.nome
FROM produto p
LEFT JOIN movimentacao_estoque m
    ON p.id_produto = m.id_produto
WHERE m.id_movimentacao IS NULL;

Etapa 14 — Desafio Final

Relatório gerencial de estoque

Crie uma consulta que apresente:

  • Produto
  • Categoria
  • Quantidade total de entrada
  • Quantidade total de saída
  • Estoque atual
  • Preço de venda

A consulta deve utilizar JOIN, SUM, CASE, GROUP BY e ORDER BY.

Ordene do menor estoque para o maior.
